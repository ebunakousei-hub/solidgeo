# SolidGeo ― 立体幾何の動的作図ソフト

GeoGebra の 3D グラフィックスにあたるものです。**Windows 版（exe）と Web 版（html）**があり、
どちらも同じ幾何演算・同じ操作・同じ作図ファイルを使います。
左の道具箱からマウスで作図するか、下のコマンド欄に命令を打ち込みます。
点をドラッグすると、それに依存する対象（中点・垂線・外接球など）がすべて追従して動きます。

**外部ライブラリは一切使いません。** Windows 版は Win32 API と自前のソフトウェアレンダラだけの単一 exe、
Web 版は通信も読み込みもしない単一の HTML ファイルです。

**Web 版は日本語と English の両方に対応しています。** ブラウザの言語設定から自動で選ばれますが、
右パネルの「English」／「日本語」ボタンでいつでも切り替えられます（選んだ言語は次回も覚えています）。
座標軸はコマンドから `x軸` のほか `xAxis` / `x_axis` でも参照できます。

---

## 1. 起動

**Windows** … `SolidGeo.exe` をダブルクリックするだけです。ビルドし直すときは `build.bat`。

**Mac・iPad・その他** … `SolidGeo.html` をダブルクリック（ブラウザで開く）だけです。
インストールも通信も要りません。中身は 1 ファイルで完結しているので、
USB で渡しても、メールに添付しても、そのまま開けば動きます。

> Windows 版と Web 版は**同じ幾何演算**を使っています（C++ の `geo.h` を JavaScript へ移植したもの）。
> 作図ファイル（`.txt`）も共通なので、Windows で作った図を Mac で開けます。
> 見た目と操作もそろえてありますが、Web 版は文字描画をブラウザに任せているぶん
> 描画の細部（球の陰影など）がわずかに異なります。

```bash
g++ -std=c++17 -O3 -DNDEBUG -fno-math-errno -s -municode -mwindows main.cpp -o SolidGeo.exe -lgdi32 -luser32 -lcomdlg32 -lshell32 -limm32
```

> `build.bat` が `%TEMP%` を経由しているのは、MinGW のリンカが「立体幾何」のような
> 非 ASCII のフォルダ名を出力先にできないためです。
>
> `-march=native` は付けないでください。ビルドした機械でしか動かない exe になります。

### 非力な PC で動かすとき

- 起動時に CPU の芯の数を見て、4 つ未満なら**高画質（2 倍描画）を切った状態**で始まります。
  あとから **F2** か右パネルのチェックでいつでも入れ替えられます。
  2 倍描画は塗る画素が 4 倍になるので、ここがいちばん効きます。
- 視点を回している間・点をつかんで動かしている間は、曲線や面の分割を自動で粗くします。
  手を止めた瞬間に、元の細かさで描き直します。
- 図が変わっていないときは 3D の絵を作り直さず、取っておいた絵を貼ります。
  道具箱や右パネルを触っているあいだは 3D の計算が一切走りません。

Web 版（`SolidGeo.html`）も同じ方針で軽くしてあります。

- 描き直しは `requestAnimationFrame` で 1 フレームに 1 回にまとめます。
  マウスの移動通知は画面の更新より細かく届くことがあるためです。
- 道具箱・一覧・設定は毎回作り直さず、変わったところだけ書き換えます。
- 視点を動かしている間だけ分割を粗くします（静止画は変わりません）。
- 芯が 4 つ未満の機械では、最初から等倍で描きます。
  右の「高精細で描く」でいつでも入れ替えられます。

## 2. 操作

| 操作 | はたらき |
|---|---|
| 道具を選んで対象をクリック | 作図（必要な個数を選ぶと自動で確定） |
| 対象を選んでから道具を押す | これでも作図できます。選択がその道具に合わないときだけ選び直しになります |
| Ctrl を押しながらクリック | 「移動」のときに複数の対象を選ぶ |
| 右の「対象一覧」の行をクリック | いま持っている道具にその対象を渡します（ダブルクリックでも同じ）。<br>画面上で見つけにくい対象や、重なって選びにくい対象はこちらから指定できます。<br>道具を持っていないときは、その対象を選ぶだけです（行頭の四角は表示の切替） |
| 道具を選んで**何もない所**をクリック | そこに必要な点が自動でできる（点を先に作らなくてよい） |
| 道具を持ったまま背景をドラッグ | 視点の回転（クリックだけが作図になります） |
| 「移動」で点をドラッグ | 自由点は水平面（z 一定）内を移動。**Shift を押しながら**で高さ方向 |
| 束縛点をドラッグ | 乗っている直線・平面・球面・円の上を滑る |
| 背景を左ドラッグ | 視点を回す |
| Ctrl（Mac は Option）＋背景を左ドラッグ | **四次元の回転**（横＝XW 面、縦＝YW 面。Shift も押すと横＝ZW 面）。四次元の対象があるときだけ |
| 平面・球・多面体の上を左ドラッグ | これらは動かせない対象なので、その上からでも視点が回ります。<br>選んだまま視点を変えられます（動かさずに離せば選択になります） |
| 右ドラッグ・中ドラッグ | 平行移動 |
| ホイール | 拡大縮小（道具箱・右パネルの上ではスクロール） |
| Enter | コマンド欄に移る／「凸包」の確定 |
| Esc | 選択解除して「移動」に戻る（何もない所をクリックしても解除されます） |
| Delete / BackSpace | 選択中の対象を削除。何も選んでいなければマウスの下にある対象を消します。<br>それに依存していた対象も一緒に消え、いくつ消えたかを画面下に表示します（Ctrl+Z で戻せます） |
| Ctrl+Z / Ctrl+Y | 元に戻す / やり直し |
| **Ctrl+V**（Mac は **⌘V**） | **貼り付け**。1 行ならコマンド欄に入るので Enter で実行し、**何行もあればそのまま順に実行して図にします**（コマンド欄を触っていなくても効きます） |
| **Ctrl+C**（Mac は **⌘C**） | いまの**作図まるごと**をコマンド列としてコピー（そのまま貼り直せます）。文字を選んでいるときや、コマンド欄を編集しているときは、ふつうのコピーになります |
| F | 全体が入るように視点を合わせる |
| Home | 視点を初期状態へ |
| F2 | 高画質の切替 |

コマンド欄では ↑↓ で履歴をたどれます。

## 3. お尋ねの操作がどこにあるか

| ご要望 | 道具 | コマンド |
|---|---|---|
| 2 点を結ぶ線分・直線・半直線 | 線分 / 直線 / 半直線 | `Segment(A,B)` `Line(A,B)` `Ray(A,B)` |
| n 点がなす面（n 角形） | 面（n角形） | `Polygon(A,B,C,D,…)`（日本語で `多角形(...)`）。<br>点を 3 つ以上選び **Enter か右クリックで確定**。同一平面上でなければ作らず理由を出します |
| 3 点がなす平面 | 平面 | `Plane(A,B,C)`（`Triangle(A,B,C)` は三角形として残してあります） |
| 直線とその上にない点がなす平面 | 平面 | `Plane(l,P)`（`Plane(P,l)` でも可。線分・半直線も使えます） |
| 2 点の中点 | 中点 | `Midpoint(A,B)` |
| 角 ∠ABC の表示 | 角（3点） | `Angle(A,B,C)` … **真ん中の B が頂点** |
| 2 直線のなす角 | 角（2つ） | `Angle(l,m)` |
| 交わる 2 平面の角 | 角（2つ） | `Angle(p,q)` |
| 角の二等分線 | 角の二等分線 | `Bisector(A,B,C)` |
| 球面上の点の接平面 | 接平面 | `TangentPlane(s,P)` |
| 点から直線・平面への垂線 | 垂線 | `Perpendicular(P,l)` `Perpendicular(P,p)` |
| 直線と点から平行線 | 平行線 | `Parallel(P,l)` |
| 線分の垂直二等分 | 垂直二等分面 / 垂直二等分線 | `PerpBisector(A,B)` `PerpBisector(sg)` / `PerpBisector(A,B,p)` `PerpBisector(sg,p)` |
| 多面体の重心 | 重心 | `Centroid(h)` `VertexCentroid(h)` `SurfaceCentroid(h)` |
| 多面体の外心 | 外接球 | `Circumsphere(h)` |
| 多面体の内心 | 内接球 / 最大内接球 | `Insphere(h)` / `MaxInsphere(h)` |
| 球を簡単に作る | 球（2点）/ 球（4点） | `Sphere(A,B)` `Sphere(A,r)` `Sphere(A,B,C,D)` |

このほかに、作図を実用にするため次も入れてあります。

- **交わり**：結果が曲線になるもの（平面∩平面 →直線、平面∩球 →円、球∩球 →円）と、
  **有限個の点になるもの**があります。点になる場合は**見つかった交点をすべて作ります**。
  - 直線・線分・半直線 ∩ 平面／三角形／球／円／直線／**多面体**
  - 円 ∩ 平面／三角形／球／円／**多面体**
  - **多面体 ∩ 球**
  たとえば立方体を横切る円なら、面を出入りする 8 点がまとめて置かれます。
  線分・半直線では、その範囲の外にある交点は作りません。
  コマンドでは `Intersect(a,b)` が 1 つめ、`Intersect(a,b,3)` で 3 つめの交点を指します。

  **多面体と球の交わり**は少し特別です。ふつうは面の上の円弧（曲線）になるので点にはできませんが、
  球が多面体を貫かず「触れているだけ」なら有限個の点になり、その全部がまとめて置かれます。
  よく使うのは次の 3 つです。

  | 組み合わせ | 出てくる点 |
  |---|---|
  | 多面体 ∩ **内接球** | 面ごとの**接点**（四面体なら 4 点、立方体なら 6 点） |
  | 多面体 ∩ **最大内接球** | 球が触れている面の接点（四面体なら 4 点） |
  | 多面体 ∩ **外接球** | **頂点そのもの**（球面上の 5 点の凸包なら、その 5 点） |

  貫いている場合は「交わりが面の上の円弧になるため、点としては作れません」と理由を返します。
- **同じ場所に点を重ねて作りません。** 道具で作ろうとした点が既にある点と同じ位置なら、
  作らずに「どの点と重複したか」を下の行に出します。札が重なって読めなくなるのを防ぐためです。
  - 例：四面体と外接球の交わり → 交点は頂点そのものなので何も作らず
    「交点は A, B, C, D と重複するので、新しい点は作りませんでした」
  - 例：球面上の点 A を通る直線と球の交わり → 反対側の 1 点だけを作り
    「C を作りました（交わり）（A と重複するので作りませんでした）」
  - 交わり以外の道具（中点・垂足など）でも同じで、そのときは重なった相手の点を選んでおきます。
  - 「点」の道具で既にある点の上をクリックしたときも、重ねずにその点を選びます。
  - コマンド欄からの作図と、作図ファイルの読み込みでは、この判定は行いません
    （書いたとおりに作るため）。
- **座標軸（x軸・y軸・z軸）は最初から対象として置いてあります。** 画面の赤・緑・青の線が
  そのまま選べる対象なので、ほかの直線とまったく同じように使えます。
  - **z 軸に平行な直線** ―「平行線」で 点 → z軸 の順にクリック
  - **x 軸上を動く点** ―「点」で x 軸の上をクリック。以後その点は軸から外れません
  - このほか 軸への垂線・垂足・垂直平面、軸との距離・なす角、軸どうしの交点（原点）など
  - 名前で呼べるので、コマンドでも `l = Parallel(A, z軸)` `P = pointon(x軸)` と書けます
  - 消すことはできません。見た目を消したいときは一覧の升目か「表示 → 座標軸」で切り替えます
- **円** を対象として扱う（3 点を通る円、平面と球の交円 など）
- **対象上の点**：直線・平面・球面・円の上に束縛され、その上だけを動く点
- **垂足**、**垂直平面**、**平行平面**
- **計測**：距離・長さ・面積・体積・半径
- **中心**：円や球の中心を点として取り出します（`Center(k)` / `中心(k)`、道具は「中心」）。
  外心・内心・面の外心などを点として扱えるので、そこから直線や交わりを続けられます
- 多面体は**選んだ点の凸包**として作ります（4 点以上を選び、Enter か右クリックで確定）

### 多面体は「フォルダ」です

多面体は総体としてだけでなく、**面・辺を個別に扱えます**。

- **カーソルを合わせた部分が光ります。** 辺の上なら辺、面の上なら面、頂点の上なら頂点。
- **クリックすると、その部分が取り出されて対象になります。** 辺は線分、面は多角形になるので、
  そのまま「中点」「垂直二等分面」「垂線」「面積」などに渡せます。
  同じ部分を二度クリックしても増えません（既にあるものが選ばれます）。
- **Ctrl を押しながらクリックすると、多面体そのもの（総体）**を選びます。
  体積・外接球・重心などは総体に対して使います。
- **右の一覧はフォルダ表示**になります。多面体の行の ▸ を押すと、面（n 角形）と辺が中に並びます。
  まだ取り出していない部分は薄く出ていて、クリックするとその場で取り出されます。
  取り出した部分はフォルダの中に子として残ります。
- **各行のいちばん左の升目で表示・非表示を切り替えられます。** 道具を持っていても切り替えられます
  （升目を押した分は道具には渡りません）。多面体の升目を消すと、
  中に取り出してある面・辺も一緒に消えます。
- **選んである部分をもう一度ダブルクリックすると隠れます。**（「移動」の道具のとき）
  取り出した面だけを消したいときは、画面上でその面をクリックして選び、もう一度ダブルクリックします。
  **同じ所をクリックすればまた出てきます**（一覧の升目や Ctrl+Z でも戻せます）。
  Ctrl を押しながらなら多面体そのものが隠れます。作図の道具を持っている間は働きません
  （二度目の押下も引数を選ぶ操作なので）。座標軸は隠れません。
- コマンドでも書けます。頂点番号は 1 から数えます。
  `e1 = edge(h, 1, 2)`（1 番目と 2 番目の頂点を結ぶ辺）、
  `f1 = face(h, 1, 2, 4, 3)`（その 4 頂点がなす面）。日本語で `辺(h,1,2)` `面(h,1,2,4,3)` とも書けます。
  なお `face(A,B,C,D)` のように点だけを並べると、多面体とは無関係な n 角形になります
  （`polygon(...)` と同じ）。

## 4. 3 次元ゆえに注意が必要なところ

平面幾何の感覚と答えがずれる箇所です。ソフト側は、あいまいなまま黙って何かを返すことはせず、
定義が分かれるものは**別々の道具として用意**し、定まらないものは**理由を表示して作りません**。

**① 線分の垂直二等分は「面」になります**

`{X : |XA| = |XB|}` は中点を通り AB に垂直な**平面**です。線が欲しい場合は
乗せる平面を追加で指定してください（`PerpBisector(A,B,p)`）。

2 点のかわりに**線分そのもの**を指定しても構いません（`PerpBisector(sg)`、`PerpBisector(sg,p)`、
`Midpoint(sg)`）。道具箱でも、線分を選んでから「垂直二等分面」を押せばその場で作図されます。

**②「面」は 3 点に限りません**

「面（n角形）」の道具は点をいくつでも受け付けます。点を 3 つ以上選んで Enter（か右クリック）で確定します。
ただし **3 次元では 4 点以上が同一平面上にあるとは限らない**ので、平面に乗っていなければ作図せず
**「同一平面上にありません」**と表示します。すべてが一直線上のときも同様に断ります。
できた面は平面として扱えるので、垂線・垂足・交わり・面積にそのまま渡せます。

**③ 点が直線上にあるとき、その直線への垂線は一意に定まりません**

無数の垂線が「平面」をなすためです。この場合は作図を断り、
「垂直平面をお使いください」と表示します（`PerpendicularPlane(P,l)`）。

**④ 重心は 3 種類あります**

`Centroid`（体積重心）、`VertexCentroid`（頂点の平均）、`SurfaceCentroid`（面積で重みづけ）。
正多面体では一致しますが、一般には別の点です。

**⑤ 内心も 2 種類あります**

- `Insphere` … **全ての面に接する**内接球。四面体なら必ず存在しますが、
  面が 5 枚以上の一般の多面体では**存在しないのがふつう**です。存在しなければ理由を表示します。
- `MaxInsphere` … **最大の内接球**（チェビシェフ中心）。有界な多面体なら必ず存在します。
  4 枚の面の組をすべて調べて厳密に求めています。

**⑥ 外心は存在するとは限りません**

全頂点が同一球面上にあるときだけ存在します。最小二乗で中心を求めたあと全頂点の残差を検査し、
乗っていなければ「外接球は存在しません」と表示します（四面体なら必ず存在）。

**⑦ 角の記法**

`Angle(A,B,C)` は**真ん中の B を頂点とする角**です。「点 A で交わる 2 直線 l, m 上に B, C がある」
という設定でその交角を測りたいときは `Angle(B,A,C)` と書いてください。
2 直線のなす角は鋭角に、2 平面のなす角は 0°〜90° に正規化しています。

## 5. 作図ファイル

作図は**コマンドを 1 行ずつ並べたテキスト**として保存・読込できます（右パネルのボタン）。
中身は人が読めるので、テキストエディタで直接書いても構いません。`#` で始まる行は註釈です。

ファイルにしなくても、**そのテキストをコピーして Ctrl+V（Mac は ⌘V）で貼り付ければ、そのまま図になります**
（1 行だけならコマンド欄に入るので Enter で実行。何行もあれば読込と同じ手順で順に実行します）。
逆に **Ctrl+C** で、いまの作図をこの形のテキストとして取り出せます。
貼り付けは**いまの作図に足す**ので、同じ名前の対象があると「その名前は使われています」で断られます。
まっさらにしたいときは「全消去」してから貼り付けてください。

```
# 四面体とその外接球・内接球
A=(0,0,0)
B=(4,0,0)
C=(0,4,0)
D=(1,1,4)
h1=Hull(A,B,C,D)
s1=Circumsphere(h1)
s2=Insphere(h1)
g1=Centroid(h1)
```

コマンド名は日本語でも書けます（`中点(A,B)`、`球(A,B)`、`凸包(A,B,C,D)`、`外接球(h1)` など）。
数は `1.5e-7` のような指数つきでも書けます（計算結果を貼り付けるときに使います）。

座標軸は読み込む側が用意するので、ファイルには書きません（`x軸` と書いて参照するのは自由です）。
また「対象の上に乗った点」だけは、行のうしろに `@ x y z` として居場所が付きます。
この種の点は位置ではなく**媒介変数**（線分なら 0〜1 の値など）で覚えているため、
親が動けば追随します。読み込むときは、書いてある位置にいちばん近い所へ置き直します。
関数の入れ子も使えます（`Midpoint(A, Midpoint(B,C))`）。

### コマンドラインから

```bash
SolidGeo.exe --open zukei.txt              # 作図ファイルを開いた状態で起動
SolidGeo.exe --script in.txt out.txt       # 一括実行して結果を書き出す
SolidGeo.exe --selftest selftest.txt       # 幾何演算の自己テスト
SolidGeo.exe --debugui                     # 画面下に UI の内部状態を表示（不具合調べ用）
```

## 6. コマンド一覧

### 書き方

- `名前 = 式` の形。**名前は省略できます**（省略すると種類に応じて自動でつきます）。
- 関数名は**大文字小文字を区別しません**。**日本語の別名**も使えます（表の 2 列目）。
- **入れ子にできます**：`Midpoint(A, Intersect(l, p))`
- 座標は `(x, y, z)`、数は `2.5` や `1.5e-7`。`#` で始まる行は註釈です。
- `x軸` `y軸` `z軸` は最初から置いてある対象なので、名前でそのまま使えます。
- **既にある点に座標を書くと、その点が動きます。** `B = (9, 0, 0)` のように、
  もう使われている名前に座標を代入すると、新しく作る代わりにその点を動かします
  （依存している対象はすべて追従します）。ドラッグしにくい所へ正確に置きたいときに使ってください。
  - 動かせるのは**自由点**と、**対象の上に乗った点**だけです。後者は指定した座標にいちばん近い、
    その対象上の点へ寄ります（`P = (3.5, 9, -4)` と書けば、x 軸上の点 P は (3.5, 0, 0) へ）。
  - 中点や交点のように**他の対象から決まる点**、**座標軸**、**点でない対象**は動かせません。
  - 右辺が座標以外（`B = Midpoint(A,C)` など）のときは、今までどおり「その名前は使われています」です。

## 7. 実装について

- **依存グラフ** ― 対象は作った順に並び、後の対象は前の対象しか参照できません。
  したがって順に評価するだけで矛盾なく再計算できます。削除は依存しているものごと連鎖します。
- **描画** ― 自前のソフトウェアレンダラです。すべての描画物（三角形・線分・点・球殻）を
  視点からの奥行きで並べ替え、奥から順に半透明合成しています。
  平面や三角形は細かく分割してから並べ替えるので、交差していても破綻しにくくなっています。
  球だけは 1 画素ごとに視線と球の交点を解いて陰影をつけています。
- **画質** ― 静止時は 2 倍のスーパーサンプリング、ドラッグ中は等倍で追従性を優先します。
- **凸包** ― すべての三点組について「残りの点が片側に揃うか」で面を判定します。
  同一平面上の点は同じ面にまとめるので、立方体のような四角形の面も正しく出ます。
- **四次元** ― 胞（3 次元の面）は 4 点組の総当たりによる支持超平面判定で列挙し、
  各胞を超平面内の基底で 3 次元へ落として上の凸包で面と辺を得ます。
  この重い計算は**点集合が変わった時だけ**行い（座標のハッシュで見張る）、
  回転・射影・断面（胞ごとに辺と w = t の交わりを並べる）は毎フレーム O(辺の数) で引き直します。
  正多胞体 5 種の (頂点, 辺, 面, 胞) とオイラー標数 V−E+F−C = 0、
  テッセラクトの w = 0 断面が立方体になること等は自己テスト（`#selftest` を付けて開く）で検査しています。
- **PNG 出力** ― zlib を使わず、走査線フィルタと LZ77＋固定ハフマンの deflate を自前で実装しています。

### 演算核の速さ

点をドラッグしている間は毎フレーム全対象を再計算するので、ここが重いと操作感に直結します。
測ってみると時間のほとんどは凸包に食われていたので、そこを次のように直しました。

1. **基準の面を選ぶ前処理を O(n³) から O(n) に。**
   もっとも遠い点で 1 本目の軸を決め、それとの外積が最大になる点で面を決めます。
2. **三点組の判定で早く抜ける。** 点が面の両側に出た時点でその組を捨てます。
   また距離を測るのに平方根を使うのをやめ、2 乗のまま比べています
   （`|d| > ε|n|` を `d² > ε²|n|²` として判定）。判定用の配列も 1 本使い回します。
3. **頂点がひとつも動いていなければ、前に求めた面と辺をそのまま使い回します。**
   多面体と無関係な点を動かしているだけのときは、凸包を計算し直しません。

同じ機械で測った結果（立方体＋その面・辺・外接球・内接球・重心など対象 24 個。3 回の最良値）:

| | 旧 | 新 | |
|---|---|---|---|
| 全体の再計算 | 0.0226 ms | 0.0027 ms | 8.4 倍 |
| 多面体と無関係な点を動かす | 0.0203 ms | 0.0028 ms | 7.3 倍 |
| 多面体の頂点を動かす | 0.0210 ms | 0.0179 ms | 1.2 倍 |
| 凸包 n=20 | 0.2550 ms | 0.0757 ms | 3.4 倍 |
| 凸包 n=30 | 1.3367 ms | 0.2598 ms | 5.1 倍 |

つぎに重かったのが**交わりの点**でした。`Intersect(a,b,1)` `Intersect(a,b,2)` … は
どれも「a と b の交点をすべて求めてから n 番目を取る」ので、交点 8 個の図では
まったく同じ計算が毎フレーム 8 回走っていました。そこで

4. **1 回の再計算のあいだ、同じ (a,b) の交点は求め直しません**（`Doc::isectPoints`）。
5. 交わりの計算を「曲線になる側」（`intersectCurve`）と「点になる側」（`intersectPoints`）に
   分けました。評価では曲線かどうかを先に決めてから点を求めるので、無駄な往復がありません。

| （交点を置いた図で） | 旧 | 新 | |
|---|---|---|---|
| 円と立方体の交点 8 個の図の再計算 | 0.0307 ms | 0.0065 ms | 4.7 倍 |
| そのうえで円を動かす | 0.0308 ms | 0.0065 ms | 4.7 倍 |
| 多面体と内接球の接点 6 個の図 | 0.0113 ms | 0.0040 ms | 2.8 倍 |

Web 版にも同じ手当てをしてあります（同じ作図で 0.101 ms → 0.018 ms、凸包 n=30 は 6.73 ms → 1.30 ms）。

あわせて、同じことをしていた箇所をまとめました ―
「平面とみなせる対象か」の判定（平面・三角形・n 角形）は `objFacePlane` の 1 か所に、
多角形の内外判定は `pointInLoop` に、多角形の作成は `makePolygon` に、
「その上に点を置ける対象か」は `kindCanHostPoint` に集約してあります。
多面体と球の交わりも、面ごとの距離を測る一巡と接点を拾う一巡をひとつにまとめました。
UI 側でも、一覧の面と辺を並べる処理はひとつのループにまとめ、
辺・面の見比べ方は `subMatches` の 1 か所に集約したうえで、
一覧では「その多面体から取り出してある子」だけを探す範囲にしています。
Web 版では対象の参照（`Doc.get`）を総なめから二分探索に変え、
削除の連鎖判定と自動命名も、毎回の走査をやめて一度だけ集めるようにしました。

### 検証の状況

`--selftest` は次を確認し、**全項目合格**しています。

- 中点・直線・線分・半直線・三角形・平面の生成と、平面の法線
- 直線と（その上にない）点からの平面。引数の順序を入れ替えても同じ平面になること、
  線分でも受け付けること、点が直線上にあるときは作らずに理由を返すこと
- ∠BAC = 90°、∠ABC = arctan(3/4)、2 平面のなす角 = 90°、角の二等分線の向き
- 平面／直線への垂足と垂線、平行線の向き、垂直二等分面が中点を通ること
- 球（中心と点／4 点）、3 点を通る円の半径、接平面の法線
- 直線∩平面、平面∩平面、平面∩球（交円の半径）
- **2 平面の交線が「通る点」まで正しいこと**（原点を通る交線だと、点が原点対称にずれていても
  同じ直線になってしまい気づけないので、原点から離れた所で確かめる）
- 直線と立方体の交点がちょうど 2 個で、入る点と出る点が正しいこと
- 線分にすると範囲外の交点を拾わないこと
- 円と立方体の交点がちょうど 8 個で、どれも面上かつ円周上にあること
- 立方体と内接球の交わりが 6 点、四面体と内接球の交わりが 4 点で、
  どれも球面上かつ面上にあること（引数の順を入れ替えても同じ）
- 四面体と外接球の交わりが頂点 4 個そのものになること、
  手で打った丸めのある座標でも球面上の 5 点がそのまま 5 点として出ること
- 面を貫く球では点を作らず、理由（円弧になる）を返すこと
- 座標軸：最初から 3 本あること、向きと原点、z 軸に平行な直線、x 軸に垂直な平面、
  軸までの距離となす角、軸どうしの交点、軸上の点が軸から外れないこと、軸は消せないこと
- 保存して読み直すと、対象の数も名前・種類・値もそのまま戻ること
  （2 直線／2 平面のなす角、直線と点からの平面、中心と半径の球、4 点の球、
  乗せる平面つきの垂直二等分線、点からの n 角形、対象上の点の居場所 まで含めて）
- 既にある点と重なる点は作らないこと ― 外接球との交点は 1 つも作らず名前を伝える、
  球面上の点を通る直線では重ならない側だけを作る、内接球の 4 接点はそのまま作る、
  中点が重なるときは作らずに相手の点を選ぶ
- 四面体：体積 1/6、F=4・E=6、体積重心と頂点重心、外接球の中心、
  内接球の半径 1/(3+√3)、最大内接球が内接球と一致すること
- 立方体：体積 1、表面積 6、F=6・E=12、外接球 √3/2、内接球 1/2
- 外接球が存在しない配置では作図せず理由を返すこと、それでも最大内接球は求まること
- 距離（2 点間、点と平面）
- n 角形：4 点から面が作れて面積が正しいこと、3 点でも作れること、
  **同一平面上にない 4 点では作らず「同一平面上にありません」と返すこと**、一直線上でも断ること
- **親を動かすと子も動くこと、親を消すと子も消えること**
- 細工された作図ファイルに耐えること ― 深い入れ子・長すぎる名前・多すぎる引数・
  範囲外の頂点番号・桁あふれする数・閉じ括弧の無い行・無限大の座標を、
  どれも「その行だけ失敗」として断り、残りの作図が壊れないこと
- コマンドで既にある点を動かせること ― 対象は増えず、依存する対象が追従し、
  対象上の点は対象から外れず、他から決まる点・座標軸・点でない対象は動かせないこと
- 立方体から辺を取り出してその中点がとれること、面を取り出して面積・垂線・垂足が使えること、
  多面体の頂点を動かすと取り出した辺も伸びること、作図ファイルから読み直しても同じになること

### 壊れた入力への備え

作図ファイルは外から渡されることがあるので、**どんな中身でも落ちない**ようにしてあります。

- **入れ子の深さは 32 まで**。式の解析は再帰なので、`midpoint(midpoint(…` を何千段も重ねた行は
  スタックを食い潰します（実際に古い版はそれで異常終了しました）。深さを数えて断ります。
- **名前は 64 文字まで／引数は 64 個まで**。長い名前を固定長の入れ物に混ぜないよう、
  保存時の書式も「数だけを整形して名前は文字列として繋ぐ」形にしてあります。
- **頂点番号・交点番号は範囲を検査**します。`1e300` のような桁あふれする数も弾きます
  （double から int への変換は範囲外だと未定義動作になるため、必ず 1 か所を通します）。
- **無限大や NaN を持った対象は「作れなかった」ことにします**。`(1e400, 0, 0)` のような座標は
  読み込み時に断り、計算の途中で発散したものは評価の最後で落とします。
  これらを描画に流すと画素の範囲計算が壊れるので、入口と出口の 2 か所で断ち切っています。
- **読み込むファイルは 16 MB まで**。取り違えて巨大なファイルを開いても固まりません。
- 途中で切れた行（`midpoint(A,B` など）は、その行だけ失敗として報告し、残りは読み続けます。

`-Wall -Wextra -Wshadow` を付けたビルドで**警告 0** です。

### 既知の限界

- 半透明どうしが交差している場合、並べ替えによる描画なので前後関係がわずかに乱れることがあります。
- 凸包の計算は三点組の総当たりなので、点数が多い（数十以上）と重くなります。
  （早く抜ける工夫は入れてありますが、次数そのものは n³ のままです。
  手で打つ点の数ならまず問題になりません。）
- Windows 版は Windows 専用です。Mac などでは `SolidGeo.html`（Web 版）をお使いください。
- Web 版は自己テストを内蔵しています。`SolidGeo.html#selftest` で開くと全項目を実行し、
  タブのタイトルに PASS / FAIL が出ます（詳細はブラウザのコンソール）。
